/* 
------- Assignment-01 ------- 

Description
We want to model a concurrent system given by a lift of a building with N floors and its users.
At each floor there could be multiple users (up to M)
that want to use the lift.
The lift has a capacity of only one user at a time.
At each floor users have a button to call the lift.
Inside the lift, the user has buttons to select the floor to go.
Users getting the lift on some floor should be served in order using a first-come-first-served/FIFO policy.
An alarm signal could be generated by a fire alarm system: in that case,
the lift would interrupt current activities,
move to the ground floor, open the door and wait, until some external signal
about the alarm being solved is received.
*/
const N=3
const M=2
range LEVELES = 0..N
range USERS_AT_LEVEL = 0..M

/* enter_lift = lock of the elevator resource (by relabeling) */
USERS = WAITING[0][0]
WAITING[f:LEVELS][u:USERS_AT_LEVEL] = (when u < M call_lift[f] -> enter_lift[ll:LEVELS] -> INSIDE[f][u])
INSIDE[f:LEVELS][u:USERS_AT_LEVEL] = (select_level[ls:LEVELS]-> move -> exit/*[fl:LEVELS] ->*/ WAITING[f][u+1]).

/*LOCK = (acquire -> release -> LOCK).*/
